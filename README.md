# AntSeed 3D 🐜🌱

Interactive 3D story website built with Three.js — a lonely ant plants a glowing seed and grows a whole colony. Includes a **Dry Season** tower-defense game mode.

Static site — no build step.

## Run locally
```bash
npx serve .
```

## Deploy to Vercel
1. **Via Dashboard** (easiest): go to [vercel.com/new](https://vercel.com/new) → drag & drop this folder → Deploy.
2. **Via CLI**:
```bash
npm i -g vercel
vercel
```
Vercel auto-detects it as a static project (no framework). No build command, no special settings needed.
